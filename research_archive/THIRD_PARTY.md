# Existing software and data licenses

"Third-party" means software or data from outside the original Tomahawk research.
It does not identify a co-owner of the Tomahawk reactor design.

Research programs may depend on tools such as DESC, FreeCAD, NumPy and BOUT++.
Using a dependency does not by itself mean its source code is included in this
archive. Any bundled copy retains its own license and notices.

One explicit existing license file was identified in the indexed original packages:

- `Tomahawk_TF48_16FieldPeriod_16T_MGRID_Complete.zip`
  → `Tomahawk_16T/inputs/optical_data/LICENSE`: **CC0 1.0 Universal**.

That notice is preserved inside the original archive. The license-file scan is an
inventory aid, not a claim that every embedded component has been independently
audited. Existing credits, source references and notices are preserved in all originals.
