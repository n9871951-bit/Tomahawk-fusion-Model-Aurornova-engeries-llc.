# Tomahawk Rev2.5 CAD-A2 clean input package

This archive is the matched provisional-input package for the Tomahawk CAD-A2
integrated screening workflow.

## Duplicate-file correction

This clean package contains exactly one material-region map:

`NEUTRONICS/material_region_map.csv`

That file is the canonical map referenced by
`NEUTRONICS/openmc_input_manifest.json`. Do not combine it with an older copy
from another Tomahawk package. If an upload service creates a second file such
as `material_region_map (1).csv`, keep the canonical path above and remove or
ignore the stale duplicate before running.

## Package contents

- `MHD/`: MHD input, profile sweep, legacy coil table, CAD-A2 centerlines, and
  CAD-A2 coil-current schedule.
- `CFD/`: CHT parameter sweep and CFD case manifest.
- `CHF/`: CHF post-processing input.
- `NEUTRONICS/`: one material-region map, OpenMC input manifest, and source
  sweep.
- Root files: `dataset_manifest.json` and
  `Tomahawk_Continuous_Run_Config.provisional.json`.

## Status and provenance

These are CAD-A2 model-derived screening inputs, not measured data, as-built
coil records, equilibrium results, solver outputs, or hardware qualification.
The CAD-A2 coil currents are model-derived. The package manifest records the
SHA-256 checksums for the supplied files.

## Required before a qualified run

The continuous-run configuration intentionally leaves solver commands unset.
A qualified run still requires the real MHD equilibrium inputs, PF/shaping
coils and free-boundary data, CFD mesh and transport heat source, CHF
correlation or LUT, DAGMC geometry, isotope/material cards, evaluated nuclear
data, and validated local fields. The CAD-A2 TF-ripple screen remains a
controlling screening check and does not by itself establish confinement.
